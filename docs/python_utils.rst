python\_utils\.types module
---------------------------

.. automodule:: python_utils.types

.. note::

   ``python_utils.types`` re-exports everything from :mod:`typing`,
   :mod:`typing_extensions` and :mod:`types`, plus the lightweight aliases
   below (defined in a stdlib-only module so importing them stays cheap):
   ``Scope``, ``OptionalScope``, ``Number``, ``DecimalNumber``,
   ``ExceptionType``, ``ExceptionsType``, ``StringTypes``, ``delta_type`` and
   ``timestamp_type``. The shorthands ``O`` (``Optional``) and ``U`` (``Union``)
   are kept for backwards compatibility.
